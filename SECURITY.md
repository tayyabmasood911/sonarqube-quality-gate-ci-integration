# Security Policy

## Supported Versions

Only the latest release on the `main` branch is actively supported with security updates.

| Version | Supported          |
|:--------|:------------------:|
| main    | :white_check_mark: |
| < main  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or credential leakage vector within this SonarQube integration suite:

1. **Do not create public GitHub issues or discussions**.
2. Contact maintainer **Tayyab Masood** at **tayyabmasood911@gmail.com** with the subject `[SECURITY VULNERABILITY] sonarqube-quality-gate-ci-integration`.
3. Provide full reproduction steps, affected scripts, and remediation recommendations.

All reports will be acknowledged within 24 hours and addressed promptly.
